# Internal engineering archive

Historical phase reports, long-form design notes, and proof kits from private development.

These files are kept for provenance. They are **not** the product docs.

- Prefer [../launch/](../launch/) and the root [README](../../README.md) for public-facing material.
- Paths inside older reports may reference local machines (for example `/home/mela_ai/...`) and Discord message ids from build sessions.
- Proof kits under `artifacts/` are large and mostly retention evidence, not runtime requirements.

| Path | What it is |
|------|------------|
| `PROJECT_STATUS.md` | Rolling delivery / acceptance log |
| `AgentIntersect_WorldDD.md` | Long-form design document |
| `PHASE_*_REPORT.md` | Per-phase closure reports |
| `ANIMATION_CONFIRMATIONS_REPORT.md` | Animation milestone acceptance notes |
| `artifacts/` | Phase proof kits |
| `evidence/` | Small phase-0 review notes |
