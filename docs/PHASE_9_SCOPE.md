# Phase 9 frozen scope

1. **Provider/version:** Entirely local/self-hosted Yjs provider, abstracted behind `@agentintersect-world/sync-yjs`. Pin exact versions: `yjs@13.6.31`, `y-websocket@3.0.0`, `y-indexeddb@9.0.12`, `y-protocols@1.0.7`, and `ws@8.21.1` only where directly needed. No PartyKit, hosted relay, public rooms, or internet discovery.
2. **Identity/ownership:** Strict `aiw.presentation/0.9` document. One deterministic opaque room/document ID derived from the authoritative World workspace/repository identity and schema domain (never absolute path, file bytes, label, token, or human account). All peers/views and owned-agent projections belong to one trusted operator; ephemeral peer/view IDs are scoped to that document. Maximum 16 connected awareness peers.
3. **Presentation-only schema:** Durable roots are only metadata with opaque IDs/schema, object layout overrides, annotations, bookmarks, and phase-board visual layout. Ephemeral awareness is limited to peer/view identity, safe display/color token, owned-agent/avatar/focus object IDs, bounded cursor/camera state, activity status, and presenter/follow relation. Commands, command-shaped fields, files/content/diffs, terminal/test output, evidence bodies, prompts/raw memory, secrets/tokens, absolute paths, executable URLs/HTML, and AgentIntersect authority are forbidden. Validate at entry and projection; escaped plain text only. Presentation traffic can never call command intent code or mutate repository files.
4. **Awareness lifecycle:** Heartbeat every 10 seconds, abrupt-expiry at 30 seconds, immediate removal on clean disconnect, never persisted. Durable presentation state remains. Presenter/follow is advisory ephemeral state; disconnecting the presenter automatically stops following without changing durable state.
5. **Durability/retention:** Browser offline persistence uses `y-indexeddb` keyed only by opaque document ID. The World local server owns an atomic checksum-protected local Yjs snapshot plus bounded update tail. Max incoming update 128 KiB; max compacted document 8 MiB; compact at 128 retained updates or 1 MiB tail; retain at most 20 documents and expire inactive documents after 30 days. Corruption fails closed to the verified previous/last-good snapshot when possible. Provide explicit local/trusted-LAN presentation-authorized delete and a sanitized deterministic JSON export capped at 1 MiB; neither can include prohibited fields. Delete requires exact document ID plus explicit confirmation and clears server state; browser local cache has an explicit clear action.
6. **Offline/conflict/orphans:** Reconnect exchanges Yjs state vectors and converges offline edits. Stable IDs plus field-level Y.Map entries minimize conflicts; concurrent edits use deterministic CRDT convergence/LWW per field and never claim exclusive authorship. Missing World object references remain durable as explicit orphans instead of being deleted; only the local authoritative World projection may attach a current safe label, never a shared path. Reappearance of the same opaque object ID resolves the orphan.
7. **Network/authority:** Default loopback only. Trusted-LAN is an explicit existing `networkScope=lan` opt-in, limited to private/link-local addresses, exact allowed Origin/Host, no discovery, and a dedicated presentation bearer/token path separate from the Phase 7 command token. Use short-lived single-use presentation join tickets and do not place long-lived tokens in WebSocket URLs or persisted/browser-shared state. Loopback may issue a ticket to an allowed local origin without the LAN bearer; LAN ticket issuance requires the dedicated configured bearer. Presentation credentials grant no HTTP command authority, and command credentials grant no presentation authority. Loopback uses ws/http locally; trusted-LAN plain transport is allowed only as an explicitly configured same-operator trusted-LAN mode with a visible unencrypted warning, while TLS may be supplied by an operator-controlled reverse proxy. No built-in public TLS/cert/account system in Phase 9.
8. **Deterministic acceptance/bounds:** Build a World-owned two-context same-machine fixture/transcript proving: both contexts join one opaque document; awareness/owned-agent focus appears; annotations, bookmarks, layout, presenter/follow converge; concurrent and offline edits converge after reconnect; clean and abrupt disconnect clear awareness; server restart recovers byte-stable durable presentation state; orphan/reappearance behavior works; sanitized export/delete work; at/over update/document/count bounds are truthful; traffic contains no absolute paths/content/tokens/command authority; a synthetic command-shaped Yjs update is rejected/ignored and creates zero command intents/jobs. Use two browser contexts, bounded finite payloads, serialized tests, Playwright `--workers=1`, and no unbounded producers. Trusted-LAN smoke is optional when the environment cannot provide a second owned machine/interface; test the LAN address/token/origin contract deterministically regardless.
